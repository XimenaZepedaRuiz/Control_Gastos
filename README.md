# Sistema de Control de Gastos Personales

## Descripción

El Sistema de Control de Gastos Personales es una aplicación desarrollada en Python que permite a los usuarios registrar, consultar y eliminar sus gastos, así como conocer el total de dinero gastado.
El proyecto tiene como finalidad desarrollar una aplicación sencilla que permita llevar un mejor control de los gastos personales.

## Objetivo

Desarrollar una aplicación sencilla para registrar y administrar gastos personales, aplicando una metodología ágil y utilizando GitHub para organizar, documentar y controlar el desarrollo del proyecto.

## Tecnologías utilizadas

- Python: lenguaje de programación utilizado para desarrollar la aplicación.
- Flask: framework utilizado para crear la aplicación web.
- HTML: estructura de las páginas.
- CSS: diseño y presentación de la interfaz.
- GitHub: plataforma utilizada para alojar el repositorio y gestionar el proyecto.

## Metodología

### Metodología seleccionada: Kanban

Para el desarrollo del proyecto utilizaremos una metodología ágil basada en Kanban.

Elegimos Kanban porque el proyecto es pequeño, el uso de un tablero permite visualizar las actividades pendientes, las actividades que se encuentran en desarrollo y las actividades terminadas.
El tablero se organizará en tres estados:

- To Do: actividades pendientes de realizar.
- In Progress: actividades que se están realizando.
- Done: actividades terminadas.

## User Stories

- Como usuario, quiero registrar un gasto indicando su descripción y cantidad para llevar un control de mis gastos.
- Como usuario, quiero visualizar mis gastos registrados para conocer en qué he utilizado mi dinero.

- Como usuario, quiero conocer el total de mis gastos para saber cuánto dinero he gastado.

- Como usuario, quiero eliminar un gasto registrado para corregir información que ya no necesito.

- Como usuario, quiero salir de la aplicación de forma segura cuando termine de utilizarla.
